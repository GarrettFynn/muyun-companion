# MuYun Companion 性能预算与工程约定 v1.0

日期：2026-10-14 ｜ 状态：生效（0.6.1 起按此执行，0.7.0 起随发版附实测对照表）

> 目标：效果不打折的前提下给出可核验的性能承诺。方法论承自 obsidian-universal-ui-translator 项目（预算表 + 真机实测），按本插件形态裁剪。

## 一、交互路径预算表（每版发版附件的模板）

当前基线为 0.6.1 实现形态；「实测」列在 0.7.0 发版时首次填写（Performance API 打点，见第三节）。

| 交互路径 | 预算 | 依据 | 实测 |
| --- | --- | --- | --- |
| 滚动帧（进度条+时长+面包屑+聚光灯+小地图，rAF 合批后单帧总开销） | <1.5ms | 60fps 帧宽 16.7ms 的 <10%，Obsidian 自身渲染占其余 | **0.00–0.60ms**（2026-10-14 真机实测，典型 0.10–0.20，峰值仍低于预算 40%） |
| 折叠动画启动（FLIP 快照 + 反向 transform，一次性） | <4ms | 不在滚动热路径，启动一次 | 待补（本轮未采样） |
| 刻度重绘（布局/文档变化时，`_tickKey` 去重后） | <2ms | 每次布局变化至多一次 | **0.30ms**（2026-10-14） |
| 状态栏单项更新（值比对去重命中后） | <0.3ms | 滚动帧内的高频项 | 待填 |
| data.json 写盘频率 | ≤2 次/秒 | 400-800ms 防抖统一约束 | 单次 **1.90ms**（2026-10-14；频率受防抖约束未观测到突发） |
| 非折叠点击的捕获监听开销 | <0.05ms | 两次 closest 即返回 | 待填 |
| onload 数据层初始化（含 ≤0.5.0 迁移路径） | <15ms | 一次性，冷启动容忍度高 | 待补 |

## 二、两条硬规矩

1. **滚动路径禁止读写交替**（layout thrashing 防护）：任何 `getBoundingClientRect` / `offsetTop` 读后紧跟样式写、再读再写的交替模式一律禁止。合法模板是 FLIP 的两段式——先全量读（快照），后全量写（apply）。新代码 review 时按此检查。
2. **新功能先填规模上限再写码**：DOM/数据规模上限表是硬约束，任何新功能在实现前先声明自己在上限表中的行。

### 规模上限表（0.6.1 现行值）

| 项 | 上限 | 超限行为 |
| --- | --- | --- |
| FLIP 动画行块 | 视口内 + 240px 缓冲 | 视口外不动画（直接终态） |
| 进度条刻度 | 60 个 H2 | 超过隐藏刻度 |
| 面包屑链 | 64 字符 | 截断保留最后两级 |
| store（续读位置） | 400 条（LRU） | 淘汰最旧 |
| stats.days | 120 天 | **折入 months**（v1.1 起，不再丢弃） |
| stats.notes | 200 条 | 淘汰最旧 |
| 小地图悬停预览/热图 | 既有实现 | — |

## 三、实测手段（0.7.0 引入）

- **打点**：`debugMode` 设置项（默认关）门控的 `console.time/timeEnd`，覆盖预算表全部路径。注：门控 console 在官方自动审查里是已知「有意设计 Warning」，勿修。
- **真机 profile**：CDP 接入 Obsidian（translator 项目已验证可行）跑 Performance 面板，滚动/折叠各采样 10s，取主线程脚本耗时对预算表填数。
- **发版附件**：每次 tag 的 Release body 追加「性能对照」小节（预算 vs 实测 vs 结论），超标即阻塞发版。

## 四、已内置的六道防线（背景，为何预算可信）

滚动联动 rAF 合批；写盘 400-800ms 防抖；`refreshSoft` 条件求值（未开启的功能不计算）；面包屑/剩余时间/刻度值比对去重（未变不碰 DOM）；FLIP 只处理视口内行块；降级链（效率模式 `body.muyun-lite` + `prefers-reduced-motion` 全关动画，最坏情况零动画开销）。

## 五、审查合规备忘（自动审查 Error 级，历次教训）

- manifest 描述禁 "Obsidian" 一词；描述结尾须 ASCII 标点。
- 禁 `navigator.*`（除 `navigator.clipboard` 官方钦点剪贴板 API——在册为 Recommendation，有意保留）。
- 设置页禁自建 HTML 标题元素（用 Setting API）。
- 门控 console.log、跨 realm 的 createElement 为有意设计 Warning，勿修。
